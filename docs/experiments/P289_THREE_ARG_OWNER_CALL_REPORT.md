## Minimal implementation and independent definition

Only same-unit known-direct finite shape: two same-typed flat ordinary
ptr<H>/Allocation/LifetimeDomain packets and one Copy ptr<H>, returning a
two-member aggregate of that packet type. Nominal/function names confer no
special privilege. The exact source signature is not a sufficient certificate.

`check_definition` clones only the registry, clears caller state, recursively
builds unmatched type-only formals (A.region=0, D.identity=0, p has no root), and
creates the third Copy token with no synthetic place/R/A/D/provenance. It checks
actual source body, all normal nonCopy obligations and exit dependencies before
publishing any function unit. Shared `nl_three_owner_body` then checks a closed
pure complete two-packet assembly and explicit whole Return (optional one local
result binding), exact formal use/bijection and no effects/loan/ref escape.
No release precondition is fabricated because this pure body has no release.
The independently defined finish_root/finish_two still enforce actual relational
release obligations. Definition failures roll back the entire unit.

Actual call consumes the two whole caller inputs, copies the third token,
replays the already checked body on actual values, and records owned
entry/returned/received snapshots. The validator checks component IDs/facts,
nonCopy/current carrier uniqueness, distinct donor/formal/result placements,
original physical root/incarnation/backing/domain conservation, and Copy token
metadata/type/availability. A pure transport body never dereferences the link,
never infers Matched, and never promotes it to Allocation/Domain/ref authority.
A stale Copy link is therefore harmless here; actual requiring operations remain
responsible for provenance/current-root checks.
