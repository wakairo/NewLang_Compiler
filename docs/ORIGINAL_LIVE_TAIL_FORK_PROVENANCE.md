## Owned proof and state contract

`src/packet_fork.c` owns the bounded evidence predicate/postcondition builder.
The fragment owns a pre-fork parent snapshot and a parent-derived closed-tail
snapshot. Each separately owned arm retains its own pre-pattern snapshot and
borrows the enclosing fragment through the fragment ownership tree.

The inherited mapping is explicitly **the identity map on the exact cloned
ancestor prefix**, qualified by those distinct world pointers. Validation
compares the prefix's values, availability, places/incarnations/current facts,
occurrences, scopes, backing contents/properties, domains and registry shape,
including the fact/incarnation high-water marks. It is not a claim that equal
numbers across arbitrary worlds denote the same object. Post-fork IDs and facts
are outside that map. No new hypothetical payload may establish an owner fact.

Whole receiving is admitted only after:

1. The original owned producer certificate is valid in its owned entry/return
   worlds, including its independent conditional definition and actual call.
2. The common parent holds the unique Available packet binding. Its original
   ptr/A/D members still have the producer's identities and aggregate carrier.
   The same heap root incarnation/current fact, full backing and governing
   domain are live. Captured dependencies or an active loan are conservatively
   refused by this small entry profile.
3. The child's entry is the exact qualified clone of that parent. After ordinary
   identifier consume-out, current child state must still prove the original
   live relation; type-only identity never suffices.

The checked whole-receiving node records the ancestor fragment/match, exact
child world, child entry snapshot and original packet ID. A sibling certificate
or an identical numeric context clone cannot replace that qualifier.

Every terminal call still runs the existing actual entry checker. Owned evidence
retains its independent definition/body, checked argument nodes/donor/formal
bindings, entry snapshot and exact original O/R/D/A relation. Each arm must
prove one whole receive, one actual terminal call and the closed-tail post-state.

The postcondition is constructed **solely from the parent**, before inspecting
arm results: packet consumed/ended, original tail EndRoot, original A/D ended,
original region/domain dead, head state unchanged/live. Both complete arm
prefixes must equal that target; arm suffix responsibilities must be closed.
Only after both agree is that same parent-derived prefix committed. No arm is
chosen as representative, no arm-local IDs are imported, and
`normal_frame_unchanged` remains **false**. Subsequent head cleanup remains a
separate explicit source operation.

The consumed Copy policy temporary is projected out consistently: its payload
is ended and its dead sum payload link cleared. It carries no owner authority;
this projection does not change the surviving source policy binding.

Construction runs inside the existing private transaction. Snapshots and failed
fragments are owned/destroyed normally; borrowed ancestry is never followed by
a destructor. Allocation-free structural comparisons are separate from fallible
raw-integrity checks, so OOM is propagated as OOM rather than disguised as a
precision refusal. The public `nl_checked_packet_fork_valid` consumer validates
owned world qualifiers, both actual arm proofs and raw integrity, failing closed.
