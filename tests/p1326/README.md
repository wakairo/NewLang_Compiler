source or historical refusal oracle. The existing current relation authenticates
the real helper call in each distinct owned fragment; the CLI consumes that
borrow with the actual runtime phase and preserves real new/old/current values.

reaches P14 precision refusal in the adopted CHECK relation. Its original

existing helper function, current quantity mapping and old-load/store/result

Existing one-field literal, paired literal, usize/stutter, H/mixed and named

Owned tests reject altered phase, function, old/new origin, postcurrent,
loan, source and foreign owner/call instance; every restoration is checked.

function-plan owner counts unchanged, then retries. CLI OOM/flush preserves
named bytes/inode/mtime and leaves no temp. Coverage is finite, not exhaustive.

hooks read actual helper returns and old/current/sibling while the one original
is alive. Hooks write metadata only; atexit reads metadata rather than expired
field pointers. Two backedges and three source Changes/closed loans are distinct
from optimized machine-store counts.
