## Equipment

- probe.c uses ordinary source-function registration and main() checking.
  It reads only public owned getters, keeps owners alive, and qualifies IDs by
  public context/world. No host-seeded facts or private accessors are used.
- observer.py reads only actual emitted C and its Clang AST. It receives neither
  the NewLang oracle nor expected values. It discovers original storage, actual
  member writes/loads, carrier def-use, real Continue/Break and receiving bindings.
  Unknown or ambiguous C forms fail closed and preserve the original C/AST.
  Passive additions print real guest scalars/addresses. Original guest bytes are
  retained; a complete diff and role map are exported. RHS rereads permit only
  scalar carrier/literal reads with harmless casts, excluding volatile/atomic
  accesses and effects. No observer reconstruction of guest state is permitted.
- driver.py keeps all raw argv, status, stdout/stderr, sizes and hashes. CHECK and
  public observations precede guest execution. Canonically invalid acceptance,
  native mismatch, sanitizer fault and evidence loss stop affected later work.
  N07/N08 are legal scope negatives: only CHECK/emission classification, no native.
  Strict GCC/Clang O0/O2 execute both original and passive C. Separate explicit
  guest ASan and guest UBSan compile and execution receipts cover both variants.
- snapshot.py preserves the fixed commit/tree objects, all original paths/modes/
  blobs, real stage-0 index and clean worktree. Historical scripts and repository
  argv are both relocated into that genuine fixed context. Only CMake enrollment
  differs in the outer R tree; the exact inherited original CMake bytes are kept.
- register.cmake adds one RUN_SERIAL R CTest with a 600-second bound and exports
  evidence through the natural CTest log; the three workflows remain unchanged.
- export.py retains a bounded lossless tar.gz/base64 archive in each natural log.
  Executable binary hashes are recorded; disposable binaries remain outside the
  evidence archive. No inherited test/assertion/timeout or exclusion is changed.
