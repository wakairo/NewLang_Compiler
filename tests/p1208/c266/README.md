Limits and cost
---------------

This remains one pure usize-to-u8 helper, one finite predicate with literal
u8 arms, and the existing source-owned original-T current-loop slice. Both
RETURN continuation, nested/multiple predicates, nonliteral arm computation,
arbitrary effects, general world transfer and general loop invariants are
outside this capability. No general soundness or audit-locality claim follows.

The transient plan adds no retained Production allocation. Explicit-final
profiles retain three real RETURN records and their existing snapshot/anchor
cost; the prospective tests measure this cost rather than hiding it. History
archives and two short native apparatus copies add maintenance/storage cost.
The new version chain makes that integration cost explicit and reviewable.
Human-author/caller UB-prevention audit locality is still unmeasured.
