# Canonical reasoning ledger

All numerical rows in oracle.json were entered manually before any guest execution.

- R1 — Draft17.34 §§4.2/4.4/4.7 and §27.1: usize and u8 are Copy+Discardable. Identifier value-use copies the value and retains the original binding. A fresh receiving binding is not a mutable assignment. This licenses each ordinary alias link without changing its static type.
- R2 — §§5.2/5.6/6: typed literals, usize LT/EQ and representable positive ADD. Every source uses small nonnegative constants; u8 literals are within 0..255. No unsigned wrap, arbitrary arithmetic or implicit conversion is assumed.
- R3 — §§18.1/18.2/18.5/18.8: signatures are available before body checking, each call gets a fresh initialized parameter binding, argument Copy retains its scalar value, and the selected normal arm becomes helper body result and caller binding value. Different calls must not reuse an entry formal value.
- R4 — §27.4: bool condition exactly once; exactly one selected lexical arm at runtime; normal arm types must agree exactly. A literal u8 normal result has empty ordinary integer dependency; no explicit RETURN is used by any helper.
- R5 — §§27.5–27.8: initializer lookup is pre-loop outer environment; each iteration has fresh bindings; Continue takes actual outgoing values to the next header; Break returns actual iteration phase and its post-state. Break does not restore entry state. Every loop-body path explicitly continues or breaks. P2 uses the same spelling orbit for an outer seed and a fresh loop parameter; after the loop, seed_after reads the retained outer 9.
- R6 — §§16.2/17.1 (Draft17.33 bounded two-u8)/17.4: named initializer order is independent of declaration index. Each source contains exactly one complete ordinary two-u8 nominal and one original local root. The selected child is fixed; the sibling is disjoint. The scoped replace returns old, installs new and preserves root/child/sibling incarnations. Only selected/ancestor current facts change. Old scalar Copies and the pre-loop entry Copy retain their values.
- R7 — §§13.5a/13.8/19.1: ordinary integer packages have empty dependencies; Copy preserves dependencies and does not mint authority. Each loan is exactly once, its ref is confined to the body, and its scalar normal result can leave the loan. The sources contain no heap, nonCopy owner, dependency-bearing H, ref helper, recursive call or lifetime-ending operation.

The source hypotheses do not imply exact compiler acceptance. Sound conservative precision rejection is permitted by canonical loop/current-state rules. If a candidate promises the selected in-scope envelope, a failed promised case must be reported as a missed declared capability; a legal third-link probe rejected outside that envelope is coverage evidence, not a safety defect. Accepting a true type/condition/Continue/join error would be a separate concern.
