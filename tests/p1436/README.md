P1436 reuses the five immutable P1435 sources and their original oracles.
`oracle.json` is prospective; it does not rewrite the P1435 tamper FIRST.

`p1436_world_auth.unit` uses real registered `main()` artifacts. It checks
numeric proof classes, each canonical normal-arm world, foreign world/owner
rejection and the original Unknown-to-Known falsifier. The P1435 tests also
cover a genuine foreign IF arm and semantic-negative rollback/retry.

`p1436_snapshot_oom.unit` computes the existing result-state snapshot's real
byte count at its genuine call and injects that allocation failure. It checks
the wrapper hit, exact status, NULL artifact, whole-context rollback and retry.

`p1436_cli_native.integration` uses ordinary newlangc output without editing C.
It checks legacy generated bytes and named-file rejection before native runs.
Passive hooks observe the actual branch, original heap addresses/Domain tokens,
Copy result, same T field change and cleanup; they do not feed program values.
The compiler argument is portable. `P1436_EXTRA_CC` adds a second strict raw
matrix for the bounded local dual-compiler validation. Logs use distinct runs.
