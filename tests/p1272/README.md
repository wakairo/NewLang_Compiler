# P1272 direct original-H scalar read

Draft17.35 selects this source; main-f7 is the fixed adopted base. The source
reads an existing heap template's declared u8 through its own live Domain and
readonly ref, Copies the result, and initializes another real queued original
with it. The second positive changes both the nominal/member spelling and byte.
The two-u8 T nominal qualifies the selected mixed unit; no T original is created.
This does not claim the deferred link-selected Some-arm H-to-T operation.

`owned` builds actual source-owned CHECK evidence, verifies readonly field,
current package, closed loan and the existing generic body seal, rejects changed
or foreign evidence without output clobber, and destroys A with an un-restored
foreign B arm while B remains healthy. The JSON read dump is an observation,
not a serialized/importable proof or a new issuer.

`source_native.py` runs the normal CLI and source negatives, checks exact emitted
u8 def-use through the initializer, compiles the untouched C with strict C17,
then runs passive original/field/Copy/link/cleanup observers for heap0/1/2 at
O0/O2. Its allocator only supplies the source's explicit allocation failures;
the observer never writes a payload or feeds a proof/value into the compiler.

`oom` obtains a fresh allocator census for each executable. It injects every
emitter ordinal and a finite CHECK selection (first/last64, even spread and
each first reached allocator site), checks actual OOM classification, rollback,
canonical cleanup and successful retry. It reports counts and PCs rather than
claiming unexecuted ordinals or reusing a prior task's counts.

Stage0 and preparation-v2/v3/v4 sources/oracles/FIRST/RED remain preserved in the
Issue's local packets. The original Stage0 source had unselected grouping,
qualified patterns and destructuring renames; it was never regraded as green.
The tracked first positive is the exact separately frozen v4 source. Subsequent
code uses normal Git history, with no new compiler-hash generation protocol.
