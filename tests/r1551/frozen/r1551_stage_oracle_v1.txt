2. Scope and target assumptions
The observation target is ordinary usize quantity value flow:
division -> initialized local -> Copy -> function result -> caller reuse.
No resource ownership, pointer, loan, allocation, generic, loop, branch,
dynamic divisor, mixed precedence, new operator grammar or hidden
authority is introduced. All divisions have the selected flat form
existing_scalar_name / usize(decimal_digits).
The narrow target assumption for this packet is usize width W in {32,64},
with range 0 through 2^W-1 and mathematical decimal literal interpretation.
No host width or actual future CI target has been measured by this PREP.
A future execution must establish the actual target before interpreting
the results. A different width is a target mismatch, not permission to
change the frozen packet or count a negative as passed.
All ordinary positive literals are representable for W in {32,64};
all positive divisors are truly nonzero. Unsigned quotient is floor(a/b).
No overflow, wrap, saturation, resource authority or dependency erasure
is required or permitted.
