3. OBSERVER AND OBSERVATION CEILING
observer.c includes only the approved public closure and C standard headers.
It loads exact source bytes, parses the function unit, walks immutable syntax,
creates a fresh semantic context, and registers the actual function unit.
It does not seed a value/root/layout, bind a fabricated result, register a fake
signature, modify a borrowed view, cast an internal layout or inspect an oracle.
Registration-only mode never constructs the entry adapter.
Entry mode is requested only for legal originals/supplements with prior real CLI
CHECK0. It parses the separate frozen "main()\n" adapter and invokes the public
semantic checker; no text substitution, body rewriting or artificial caller facts.

Syntax records retain declaration/formal positions, actual source order, callee
spelling, source spans and branch/body structure. Checked records retain resolved
function IDs, arguments, result packages, Copy use, retained call bodies and
source/context/fragment-qualified identities. Traversal follows public root/edge
getters, not an assumed contiguous node-ID layout. Conditional arm evidence is
labelled hypothetical and never treated as the executed native arm.
Each public division/remainder view and its read-only authenticator are logged;
a false authenticator/origin mismatch stops the driver before codegen/native.

The selected headers do not expose an ordinary scalar actual-to-corresponding-
formal identity seal. Numeric equality, IDs from unrelated contexts and unit
exit0 cannot supply that proof. The driver compares only genuinely exposed
known scalar actual/result observations to the frozen independent predictions.
Missing values/calls remain explicit missing observations. No source/oracle
derived guest state or observer pass field is generated.

Every original entry returns unit. Pristine native exit0 with empty streams is
only a finite native health/unit-completion observation. No passive native
instrumentation is planned in this finite capsule. Internal native numeric
values and temporal argument order remain UNOBSERVED. Pure operations may be
optimized away. Syntax order, checked argument order, observation traversal
order and native temporal order are distinct.
