parameters, a direct field write loan with one actual replace, and one direct
nearest-target Break. Accept bound-old or inline-old, either declared field,
arbitrary names/constants, and a pure outer u8 binding as replacement. A

keep the original generic checker and its precision refusal. Nested, cyclic,
multiple Break/Change, affine aggregate, active source loan, captured Copy-call
or IF-join worlds are outside A. This is an implementation boundary, not a new
source prohibition.

prefix, not derived from coincident IDs. Caller current and r never come from
the exit snapshot. The independently owned public body keeps a stable context
pointer and receives a clone of completed actual execution. No public current
issuer or new authority is added.
