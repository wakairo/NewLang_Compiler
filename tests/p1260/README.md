# P1260: post-loop scoped Copy write

The original P1259 source and oracle are retained byte for byte in A and the
two original invalid controls. `oracle.json` was frozen before implementation
and before observing the separately authored B/unsupported/escaping-loan inputs.
The original P1259 FIRST and the initial main2fe C17 refusal remain external
evidence; they are not retroactively classified as successful compilations.

This increment consumes existing CHECK-issued evidence for one original two-u8
T kept across a complete two-allocation H match and a changing-current loop.
After the loop's real old-u8 BREAK, up to two root-level scoped writes may call
an ordinary known two-parameter helper with one Change. Its typed actual/formal
receipt and complete body are validated, and its actual result must trace to
that Change's old result through pure bindings/Copy or explicit RETURN. The
world cursor records only authenticated successive original place facts; an
active loan in historical handoff is never a permission to emit.

A writes BREAK's Copy into the other field. B reverses field declaration order,
uses a different loop/policy, explicit helper RETURN, then makes another legal
caller write. B's second call stores and returns equal bits from distinct value
packages. Both programs retain the original physical T and H0/1/2 cleanup.

The test first runs ordinary CLI CHECK/C17 and unmodified generated guests.
Only afterwards does a passive observer check live original addresses,
old-before-store, each new current, sibling, actual BREAK/caller/old results and
H cleanup under allocation quotas 0/1/2 at C17 O0/O2. The host probe validates
genuine source-owned proofs and exercises foreign same-bits CHECK instances,
wrong caller/world/root/field/loan/result/signature, and public observation
forgery. Destroying A with foreign B children and altered display counts must
leave B usable; sanitizer runs also detect leaked canonical children.

`oom.c` reuses the unchanged strict P1236/P1227 oracle. A fresh per-binary census
selects all emitter allocations and matching named-output allocations, first
registration/CHECK sites and all final seal/transaction cuts before injection.
The finite ceiling is 1024 selected trials across A/B. Required results are
actual OOM, rollback, NULL/no-publication, retry and named byte/inode/mtime
preservation. No selected allocation is omitted to satisfy the ceiling.

The first exploratory census selected 1038 trials before any injection. The
new consumer was replaying the same Copy body twice: parameter validation itself
already calls complete body validation. Removing that duplicate replay retained
all obligations and reduced the next Debug census to 680 selected trials. Both
raw censuses are preserved in the task packet.

Unsupported boundaries include arbitrary post-loop statements/control flow,
more than two post-loop calls, other originals, escaping loans and helpers whose
actual result is incoming rather than old. Language-invalid sources fail CHECK;
the legal incoming-result control remains C17 unsupported with no clobber.
No new language law, public issuer/API/ABI, semantic world, ownership ledger,
general CFG or historical SHA-generation verifier is introduced. Capability
tests do not establish general soundness or Product Value Strategy audit locality.
