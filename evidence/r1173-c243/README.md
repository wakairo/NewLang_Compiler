- `logs/` holds complete decoded job logs as returned by the GitHub log tool, encoded losslessly as UTF-8. A log larger than 900,000 bytes is split only at complete line boundaries. Concatenate its parts in the order given by INDEX to recover the exact complete decoded log. No content is omitted. These are decoded job logs, not artifact ZIP archives.
- `packets/` holds each normal job's original logged gzip/tar packet bytes as base64, with the actually checked length and SHA256, exact source log line range and member-manifest digest. Decode the base64 to recover the original compressed bytes. Repeated exports are retained and do not count as repeated executions. Some initial exports have different gzip wrapper bytes while their member bytes and modes agree.
- `raw/` holds lossless groupings of the original regular tar members: path, tar mode, byte length, SHA256 and base64 content. Parts are listed explicitly in INDEX. Decode each content value and check its length/hash to restore that member. These JSON groupings are not themselves the original tar/gzip packets. All original source, oracle, frozen execution manifests, driver, observer, public probe, generated C, observer maps, command records, stdout/stderr, owned records, observation JSON and FIRST data present in the packet are preserved.
- `FIRST-SUMMARY.json` provides derived counts and copies of each original parsed FIRST, with the original FIRST byte hash. It supplements the raw FIRST bytes; it does not supersede them. No later PASS overwrites initial RED or NOT_RUN.

A fresh GitHub read matched the original complete response exactly. The prefix bytes were retained separately and the working file restored atomically from the complete staging copy.
